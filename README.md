## 🧑‍💻 Introduction

In today’s rapidly advancing technological world, the need for efficient and user-friendly monitoring systems continues to grow. This project focuses on building a **Bluetooth-enabled Wireless Temperature and Humidity Monitoring System**, designed using the flexibility of **MIT App Inventor** for the mobile app interface.

The system uses an **Arduino Uno**, **DHT-22 sensor**, **HC-05 Bluetooth module**, and several essential electronic components to provide real-time temperature and humidity readings. This setup allows users to conveniently monitor environmental conditions directly from their smartphone.

Join us as we dive into the process of developing a reliable and effective wireless monitoring system.

---

## 🔧 Components Required

- Solderless Breadboard  
- Arduino UNO  
- HC-05 Bluetooth Module  
- DHT-22 Temperature & Humidity Sensor  
- 16×2 LCD Display  
- 100Ω Resistor  
- 4.7kΩ Resistor  
- 1kΩ Resistor  
- Male-to-Male Jumper Wires  
- Battery Clip  
- 9V Battery
